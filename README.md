# BankingApi

Simple checking account API 

## Quick start

```bash
git clone <repo>
cd BankingApi
dotnet build
dotnet run --project src/BankingApi
```

Swagger: http://localhost:5000/swagger

## What's here

Single account service with basic CRUD. No debit/credit yet — we add
that together.
